# Apple School

A frontend-only, responsive school website demo built with Next.js 15, React 19, TypeScript and Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```
Visit http://localhost:3000.

## Production
```bash
npm run build
npm start
```

Deploy by importing this repository into Vercel. No environment variables are required.

**Demo notice:** All school details, contact information, news, testimonials and imagery are illustrative. Contact and admissions forms validate locally only; no information is transmitted or stored. This project intentionally has no backend, database, authentication, student portal or payment functionality.
